# jaydigitalstudio.com

React/Vite portfolio site for [jaydigitalstudio.com](https://jaydigitalstudio.com/).

The custom domain is declared in `CNAME`. GitHub Pages deploys this repository
from the `main` branch root. Source code is organized under `source/src` by
page, section, data, hook, and stylesheet. `npm run build` writes the optimized
static application and project-route entry pages to the repository root.
